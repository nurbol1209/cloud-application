# Лабораторная работа № 8. Постановка задач программного проекта

## Цель

Освоить преобразование требований в задачи с приоритетами, зависимостями,
критериями выполнения и общим Definition of Done.

## Что сделано

Код приложения не изменялся. Создан документ
[PROJECT_TASKS.md](PROJECT_TASKS.md), содержащий:

- требования REQ-01 … REQ-05 (фильтрация по `status`, допустимые значения,
  сохранение полного списка без параметра, документация, сохранение CRUD);
- задачи TASK-01 … TASK-08 с приоритетами P1–P3, зависимостями и статусами;
- схему зависимостей;
- критерии выполнения TASK-03;
- Definition of Done проекта.

## Реализация требований

Требования реализуются в последующих работах:

- TASK-01 — ЛР № 10 (ограничение `status` через `Literal`);
- TASK-02, TASK-03, TASK-05 — ЛР № 11 (фильтрация и документация);
- TASK-04, TASK-06 — проверки после изменений.

## Вывод

Декомпозиция позволяет выполнять задачи последовательно, контролировать
зависимости и объективно определять завершённость работы.
