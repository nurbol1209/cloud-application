# Каталог секретов

Файлы с секретами исключены из Git. Создайте их локально одной командой:

```bash
python scripts/init_secrets.py
```

Скрипт создаёт:

| Файл | Содержимое |
| --- | --- |
| `lab_db_password` | пароль PostgreSQL (для режима `DB_BACKEND=postgresql`) |
| `auth_secret` | случайное значение `secrets.token_urlsafe(32)` |

В файлах хранится только значение, без `KEY=`.
Реальные значения нельзя коммитить, публиковать или выводить в логи.
