# Задачи проекта Cloud Application

Документ фиксирует требования и декомпозицию ближайшего этапа развития
приложения: фильтрация сервисов по состоянию.

## Требования

- **REQ-01.** API должно поддерживать получение списка сервисов по состоянию.
- **REQ-02.** Для поля `status` допускаются только значения `running`,
  `maintenance`, `stopped`.
- **REQ-03.** При отсутствии параметра фильтрации API возвращает полный список
  сервисов.
- **REQ-04.** Документация API должна содержать описание фильтрации и
  допустимых значений состояния.
- **REQ-05.** Существующие операции CRUD должны продолжать работать.

## Критерии выполнения TASK-03

- `GET /services?status=running` возвращает только сервисы в состоянии
  `running`;
- `GET /services` без параметра возвращает полный список;
- недопустимое значение параметра отклоняется;
- OpenAPI-документация содержит описание параметра.

## Definition of Done

Задача считается завершённой, если:

1. код реализован и запускается;
2. существующие операции CRUD не нарушены;
3. выполнена проверка корректного и ошибочного сценария;
4. документация обновлена;
5. изменения зафиксированы в Git;
6. задача отмечена как `DONE`.
