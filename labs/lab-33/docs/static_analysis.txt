2. Правила
----------

F401  импорт создан, но не используется.
      Может влиять на запуск при неудачном импорте, но обычно безопасен.
      Исправление: удалить импорт (автоматически).

F841  локальная переменная присвоена, но не используется.
      Присваивание может иметь побочный эффект, поэтому fix помечен unsafe.
      Исправление: удалить присваивание после проверки (вручную).

E711  сравнение с None через ==.
      Для None корректно использовать `is None`.
      Исправление помечено unsafe, так как меняет выражение (вручную).

I001  блок импортов не отсортирован.
      Влияет на читаемость и diff, не на выполнение.
      Исправление: organize imports (автоматически).
