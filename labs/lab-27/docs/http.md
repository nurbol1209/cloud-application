# Исследование HTTP-запросов и ответов

Приложение запущено по адресу `http://127.0.0.1:8000`.

## Успешный запрос

```bash
curl -i http://127.0.0.1:8000/status
```

Ожидаемый ответ:

```http
HTTP/1.1 200 OK
content-type: application/json

{"status":"ok","service":"Cloud Application"}
```

## Запрос к несуществующему ресурсу

```bash
curl -i http://127.0.0.1:8000/missing
```

```http
HTTP/1.1 404 Not Found
content-type: application/json

{"detail":"Not Found"}
```

## Неподдерживаемый метод

```bash
curl -i -X POST http://127.0.0.1:8000/status
```

```http
HTTP/1.1 405 Method Not Allowed
allow: GET
```

## Таблица результатов

| Запрос | Метод | Путь | Код | Тело ответа |
| --- | --- | --- | --- | --- |
| Главная страница | GET | `/` | 200 | сведения о приложении |
| Состояние | GET | `/status` | 200 | `status`, `service` |
| Описание | GET | `/about` | 200 | `name`, `type`, `language`, `framework` |
| Курс | GET | `/course` | 200 | дисциплина, ЛР, проект |
| Несуществующий ресурс | GET | `/missing` | 404 | `{"detail":"Not Found"}` |
| Неподдерживаемый метод | POST | `/status` | 405 | заголовок `allow: GET` |

## Разбор URL

`http://127.0.0.1:8000/status`

| Часть | Значение |
| --- | --- |
| Протокол | `http` |
| IP-адрес | `127.0.0.1` |
| Порт | `8000` |
| Путь | `/status` |

## Наблюдения

- Код `200` означает успешную обработку запроса.
- Код `404` возвращается, если маршрут не зарегистрирован.
- Код `405` возвращается, если маршрут существует, но не поддерживает метод.
- Заголовок `content-type: application/json` показывает формат тела ответа.
