# Лабораторная работа № 4. Формирование HTTP-запросов

## Цель

Освоить формирование HTTP-запросов, анализ кода состояния, заголовков и тела
ответа на примере Cloud Application.

## Что сделано

Код приложения не изменялся. Выполнены запросы через браузер, Swagger UI и
`curl`; результаты зафиксированы в [docs/http.md](docs/http.md).

```bash
curl -i http://127.0.0.1:8000/
curl -i http://127.0.0.1:8000/status
curl -i http://127.0.0.1:8000/missing
curl -i -X POST http://127.0.0.1:8000/status
```

В файле `requests.http` собраны те же запросы для расширения REST Client в
VS Code.

## Вывод

HTTP-запрос состоит из метода и URL; ответ содержит код состояния, заголовки и
тело. Коды `200`, `404` и `405` позволяют отличить успешный запрос, обращение
к отсутствующему ресурсу и неподдерживаемый метод.
