# Лабораторная работа № 3. Исследование сетевых параметров приложения

## Цель

Исследовать IP-адрес, имя узла и сетевой порт, а также научиться изменять
параметры запуска локального серверного приложения.

## Что сделано

Код приложения не изменялся — работа носит исследовательский характер.
Результаты и команды приведены в [docs/network.md](docs/network.md).

Ключевые команды:

```bash
hostname
ipconfig
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
python -m uvicorn app.main:app --port 8080
```

```powershell
Test-NetConnection -ComputerName 127.0.0.1 -Port 8000
```

## Вывод

Для соединения клиенту нужны адрес узла и порт. `127.0.0.1` доступен только
локально, `0.0.0.0` используется как адрес привязки ко всем интерфейсам.
Смена порта меняет адрес, по которому клиент обращается к приложению.
